# Шесть детекторов

Одна команда, шесть независимых источников evidence. Код: `participant/detectors.py` → `run_detectors(x, fs)` → список BPA.

Каждый детектор отдаёт `{"signal", "noise", "unknown"}` с суммой 1.  
`unknown` = m(Θ), незнание, не третий класс.

| Детектор | Вопрос |
|----------|--------|
| `snr` | Есть ли выделяемая энергия относительно фона? |
| `fft_peak` | Есть ли узкий спектральный пик? |
| `band_energy` | Сосредоточена ли энергия в немногих бинах? |
| `autocorr` | Есть ли повтор во времени? |
| `entropy` | Менее ли случайна амплитуда, чем у шума? |
| `periodicity` | Есть ли доминирующий ритм / модуляция? |

Первые три смотрят спектр/энергию, последние три — структуру. Это разные вопросы, не разные команды.

## Что можно менять

Пороги, окна, лаги, бины, отображение score → BPA. Новый признак — только если объясняете, что он меряет.

Нельзя: подглядывать метки (их нет в public), объявлять третью гипотезу в Θ, сдавать только график без BPA, искать «скрытое сообщение» *вместо* BPA (текст — бонус после сдачи).

## Как не запутаться

- Высокая энергия ≠ автоматически `signal`.  
- Низкая уверенность → больше массы на `unknown`, а не «натянуть» 0.99.  
- Согласие части детекторов — ещё не ответ: канон — DST **на всех шести**.  
- Конфликт между детекторами — учебный кейс: majority может быть спокоен, DST поднимет K.

Сверка и политика — [DST](https://logmaks.github.io/seti-hack-public/docs.html#dst). Общий кадр — [Intro](https://logmaks.github.io/seti-hack-public/docs.html).
